# 习近平新时代中国特色社会主义思想概论章节刷题

纯静态 GitHub Pages 网页。

## 功能

- 共 664 道题，覆盖导论及第1—17章
- 判断题、单项选择题、多项选择题
- 章节固定，章内题目每次随机
- 顶部上一题、下一题
- 提交后只显示正确答案，不提供解析
- 独立重要时间线页面
- 支持键盘：左右方向键切题，数字1—5选项，Enter提交

## GitHub Pages 部署

1. 新建 GitHub 仓库。
2. 将本文件夹中的 `index.html`、`style.css`、`app.js`、`questions.js` 上传到仓库根目录。
3. 进入 Settings → Pages。
4. Source 选择 Deploy from a branch，分支选择 main，目录选择 /root。
5. 保存后即可访问。
